# Инструкция для сбора данных

Файл с данными: `data/universities.json`. Это обычный JSON-массив.
Собирать можно в Google-таблице и выгружать в этот формат — главное,
чтобы названия полей совпадали буква в букву.

## Поля университета

| Поле | Тип | Обязательное | Пример |
|---|---|---|---|
| `id` | строка, латиницей, без пробелов | да | `"aitu"` |
| `name` | строка | да | `"Astana IT University"` |
| `short_name` | строка | нет | `"AITU"` |
| `city` | строка | да | `"Астана"` |
| `ownership` | `государственный` / `частный` / `автономный` | да | `"частный"` |
| `website` | строка | нет | `"https://astanait.edu.kz"` |
| `has_dormitory` | true/false | да | `true` |
| `has_military_department` | true/false | да | `false` |
| `programs` | массив программ | да | см. ниже |

## Поля программы

| Поле | Тип | Пример |
|---|---|---|
| `code` | строка | `"B058"` |
| `name` | строка | `"Информационная безопасность"` |
| `field` | одно из списка ниже | `"IT"` |
| `degree` | строка | `"бакалавр"` |
| `duration_years` | число | `3` |
| `languages` | массив строк | `["русский", "английский"]` |
| `tuition_per_year_kzt` | целое число тенге, без пробелов и знака ₸ | `1800000` |
| `grant_available` | true/false | `true` |
| `min_score_grant` | целое, `0` если нет данных | `110` |
| `min_score_paid` | целое, `0` если нет данных | `75` |
| `application_deadline` | строка `ГГГГ-ММ-ДД` | `"2027-07-20"` |

**Допустимые значения `field`** (другие не использовать, иначе фильтры сломаются):
`IT`, `Экономика`, `Медицина`, `Инженерия`, `Право`, `Педагогика`, `Гуманитарные`

## Правила

1. Цифры — числами, не строками. `1800000`, а не `"1 800 000 ₸"`.
2. Нет данных — ставь `0` для чисел и `null` для строк. Не пиши «нет», «-», «н/д».
3. `id` уникален и не меняется после того, как попал в базу.
4. Для каждого поля держи ссылку на источник — на защите могут спросить, откуда цифры.

## Приоритет сбора (если времени мало)

1. 15–20 вузов Казахстана с IT-направлениями — на них строится демо
2. Для каждого: город, стоимость, наличие гранта, дедлайн, сайт
3. Остальные направления и поля — во вторую очередь

Лучше 15 вузов с полными и проверенными данными, чем 100 с дырами.
Жюри проверит один-два вуза вручную, и расхождение с реальностью убьёт доверие ко всему проекту.
