# UniSearch — поиск университетов по запросу на обычном языке

Абитуриент пишет «хочу IT в Астане до 800 тысяч, нужен грант» — сервис
отдаёт подходящие программы из проверенной базы и объясняет выбор.

## Архитектура

```
Пользователь
     │  "хочу IT в Астане до 800к с грантом"
     ▼
┌─────────────────────────────────────────┐
│  Фронтенд (React / Next.js)             │
└──────────────────┬──────────────────────┘
                   │  POST /api/search
                   ▼
┌─────────────────────────────────────────┐
│  FastAPI                                │
│                                         │
│  1. ai.py      фраза  ->  фильтры       │  ← Gemini API
│  2. search.py  фильтры -> программы     │  ← обычный код, без AI
│  3. ai.py      объяснение выдачи        │  ← Gemini API
└──────────────────┬──────────────────────┘
                   ▼
           data/universities.json
        (собирает research-человек)
```

**Главная мысль для защиты:** AI не придумывает университеты. Он только
переводит человеческую фразу в фильтры и комментирует результат. Сам отбор
делает детерминированный код по нашей базе, поэтому каждая цифра в выдаче
проверяема, а сервис не галлюцинирует. Если Gemini недоступен — включается
разбор по правилам, и поиск продолжает работать.

## Файлы

| Файл | За что отвечает |
|---|---|
| `app/main.py` | HTTP-эндпоинты |
| `app/models.py` | схемы данных, единый источник правды по формату |
| `app/storage.py` | чтение базы из JSON |
| `app/search.py` | фильтры и ранжирование |
| `app/ai.py` | Gemini: разбор запроса и объяснение + запасной режим |
| `data/universities.json` | сама база |
| `API.md` | контракт для фронтендера |
| `DATA.md` | инструкция для сбора данных |

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# вставь в .env ключ с aistudio.google.com

uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000/docs — там можно нажать Try it out и
проверить любой эндпоинт без фронтенда.

Проверка поиска из терминала:

```bash
curl -X POST http://127.0.0.1:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{"query": "хочу IT в Астане с грантом"}'
```

## Деплой (Render, бесплатно)

- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Environment: добавить переменную `GEMINI_API_KEY`

## Команда

| Роль | Зона ответственности |
|---|---|
| Фронтенд | интерфейс, карточки выдачи, страница вуза |
| Бэкенд | API, поиск, AI-слой |
| Research | данные в `data/universities.json`, анализ конкурентов |
