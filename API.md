# Контракт API

Этот файл — договор между бэкендом и фронтендом. Пока он не меняется,
фронт и бэк пилятся параллельно и не мешают друг другу.

База: `http://127.0.0.1:8000` локально, на проде — адрес с Render.
Живая документация со всеми полями: `/docs`

---

## POST /api/search — главный эндпоинт

Запрос:

```json
{ "query": "хочу IT в Астане до 800 тысяч, нужен грант", "limit": 10 }
```

Ответ:

```json
{
  "query": "хочу IT в Астане до 800 тысяч, нужен грант",
  "filters": {
    "city": "Астана",
    "field": "IT",
    "max_tuition_kzt": 800000,
    "grant_only": true,
    "dormitory_required": false,
    "military_department_required": false,
    "language": null,
    "max_duration_years": null
  },
  "parsed_by": "ai",
  "total": 3,
  "results": [
    {
      "university_id": "aitu",
      "university_name": "Astana IT University",
      "city": "Астана",
      "program": {
        "code": "B058",
        "name": "Информационная безопасность",
        "field": "IT",
        "degree": "бакалавр",
        "duration_years": 3,
        "languages": ["русский", "английский"],
        "tuition_per_year_kzt": 1800000,
        "grant_available": true,
        "min_score_grant": 110,
        "min_score_paid": 75,
        "application_deadline": "2027-07-20"
      },
      "score": 0.85
    }
  ],
  "explanation": "Подобрал программы по информационной безопасности в Астане..."
}
```

Что фронт с этим делает:

- `filters` — показать чипсами над выдачей («Астана», «IT», «до 800 000 ₸», «грант»).
  Это сильный ход для защиты: видно, что система поняла человека.
- `parsed_by` — `"ai"` или `"rules"`. В интерфейсе не показывать, нужно для отладки.
- `results` — карточки. Сортировка уже сделана бэком, не пересортировывать.
- `explanation` — текст под выдачей.
- `total: 0` — показать пустое состояние и предложить убрать часть фильтров.

## POST /api/filter — форма с чекбоксами

Запрос — сразу объект фильтров (те же поля, что в `filters` выше):

```json
{ "city": "Алматы", "grant_only": true }
```

Ответ — тот же `SearchResponse`, только `query` пустой и `parsed_by: "manual"`.

---

## GET /api/universities — каталог

Параметры: `?city=Астана&field=IT` (оба необязательны).
Ответ — массив университетов целиком, с программами внутри.

## GET /api/universities/{id} — карточка вуза

Ответ — один университет. `404`, если id не найден.

## GET /health — проверка

```json
{ "status": "ok", "universities": 12, "programs": 47, "cities": [...], "fields": [...] }
```

Фронт может показать «в базе 12 вузов и 47 программ» на главной — это
хорошо смотрится на защите.

## POST /api/reload — перечитать данные

Дёргается после того, как research залил новый `data/universities.json`.
Сервер перезапускать не нужно.

## Правила, которые экономят нервы

1. Формат меняем только через общее решение в чате. Поменял поле — сразу пишешь в чат команды.
2. Фронт никогда не считает и не додумывает данные: что пришло от API, то и рисует.
3. Все деньги — целые числа в тенге. Форматирование («800 000 ₸») делает фронт.
4. Пока бэк не готов, фронт работает на замоканном ответе из этого файла.
